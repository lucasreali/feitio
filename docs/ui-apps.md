# Admin and checkout: shared rules

Imported by `apps/admin/CLAUDE.md` and `apps/checkout/CLAUDE.md`.

- React SPAs on Vite, browser only: TanStack Router with file routes (`src/routes/`) and TanStack Query, created from `create-vite` (React + TypeScript) and adjusted for the monorepo. `src/routeTree.gen.ts` is generated by the router plugin; never edit it (Biome ignores it).
- Components are built on Base UI (`@base-ui/react`), live in `src/components/ui/` of each app and are not shared between projects. Icons come from Phosphor (`@phosphor-icons/react`). Combine classes with `cn()` (`src/lib/cn.ts`) and build variants with `cva`. No shadcn/ui, no other component library, no Lucide. The `frontend-design` plugin is enabled: keep these choices over its defaults.
- Theme: colors and radius are CSS variables in `src/styles.css` (`background`, `foreground`, `primary`, `primary-foreground`, `muted`, `muted-foreground`, `accent`, `border`, `destructive`, `radius`), exposed to Tailwind v4 as theme colors. Use only theme classes (`bg-primary`, `text-foreground`); Tailwind's default palette is disabled, so `bg-red-500` does not exist. Both apps use the same variables, folder layout and the Feitio palette.
- API client: generated by Kubb from the API's `/openapi.json` (`pnpm api:generate`, with the API running) into `src/api/gen/`, which is gitignored. Never edit or test generated code. The base URL comes from `VITE_API_URL` (`.env.example`).
- TypeScript extends `@feitio/config/tsconfig.react.json`. `noUnusedLocals` and `noUnusedParameters` are off because Kubb's generated code trips them; unused code is a lint concern.
- Tests: `src/**/*.test.ts(x)` next to the code, jsdom and Testing Library, through the app's own `vitest.config.ts`.
