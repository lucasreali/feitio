# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

A client store built from the Feitio storefront starter: React with server-side rendering on TanStack Start, TanStack Router (file routes in `src/routes/`) and TanStack Query. Everything internal (identifiers, comments, docs, commits) is written in English.

## UI

- The `frontend-design` plugin (Anthropic) is enabled in `.claude/settings.json`. When using it, keep this project's choices over the skill's defaults:
  - Components are built on Base UI (`@base-ui/react`) and live in `src/components/ui/`. No shadcn/ui and no other component library.
  - Styling is Tailwind CSS with colors and radius only from the theme variables in `src/styles.css` (`background`, `foreground`, `primary`, `primary-foreground`, `muted`, `muted-foreground`, `accent`, `border`, `destructive`, `radius`). Use theme classes such as `bg-primary` and `text-foreground`; Tailwind's default palette is disabled, so raw colors do not exist. Each client's design changes the variables, not the components.
  - Icons come from Phosphor (`@phosphor-icons/react`). No Lucide.
  - Combine classes with `cn()` from `src/lib/cn.ts` and build variants with `cva`.

## API

The API client is generated by Kubb from the Feitio API's OpenAPI spec: `pnpm api:generate` writes types, Zod schemas, a fetch client and TanStack Query hooks to `src/api/gen/` (gitignored, never edit it). The base URL comes from `VITE_API_URL`.

## Commands

- `pnpm dev` starts the store on port 3003.
- `pnpm build` builds the client and server bundles and type-checks.
- `pnpm test` runs Vitest with Testing Library.
